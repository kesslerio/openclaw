# AWS Marketplace Co-Sell Guide

_Saved: Jan 29, 2026_
_Source: https://aws.amazon.com/marketplace/partners/seller-journey/co-sell_

## Overview

AWS Marketplace makes it easy for ISVs to list products, expand customer reach, and enable customers to quickly buy and deploy products.

## Building a Strong Cloud Marketplace Foundation

### 1. Product Selection

- Build and list high quality products and professional services
- Solve important use cases for cloud buyers
- Breadth and relevancy of selection is required

### 2. Partner Commitment

- Establish leadership support and buy-in
- Compensation neutrality for AWS Marketplace procurement
- Allow all transaction types (channel, renewals, net new)
- Leadership committed to AWS Marketplace strategy/goals

### 3. Sales Alignment

- Prioritize AWS Marketplace as preferred route to market
- Drive goals and enablement to sales team
- Educate on value of AWS Marketplace for customers
- Leverage channel programs to expand reach

### 4. Enablement

- Create enablement strategy for sales, operations, marketing
- Train on how to talk to customers
- Leverage AWS Marketplace tools
- Drive GTM for AWS Marketplace listings

### 5. APN Programs

- Actively participate in AWS Partner Network programs
- Use **AWS Customer Engagements (ACE)** for co-sell pipeline
- Co-sell with AWS account teams
- Leverage Partner Marketing for "better-together" messaging

### 6. Operational Excellence

- Right systems, tools, resources at global scale
- Replace one-off processes with repeatable ones

## Key Programs

### AWS ISV Accelerate Program

- Co-sell program for software solutions on/integrated with AWS
- Connects ISVs with AWS Sales organization
- Access to AWS field sellers globally (millions of active AWS customers)
- Provides co-sell support and benefits
- **Link:** https://aws.amazon.com/partners/programs/isv-accelerate/

### Incentive Programs

- Cash and credit incentives for new customers
- Help land new customers through AWS Marketplace

## Key Actions

1. Identify target opportunities for AWS Marketplace procurement
2. Work with AWS to qualify customer likelihood
3. Drive joint wins with AWS teams
