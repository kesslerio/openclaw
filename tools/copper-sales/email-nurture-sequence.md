## AUTOMATION SETUP

### Tools

- **Email Platform:** Mailchimp, SendGrid, or Lemlist
- **CRM:** HubSpot (free tier) or Airtable
- **Scheduling:** Calendly (integrated with Google Calendar)
- **SMS:** Twilio or SimpleTexting

### Workflow

1. **Lead Import:**
   - Upload CSV of 250 ClearCare agencies (from LinkedIn scraper)
   - Fields: Name, email, agency name, location, caregiver count

2. **Sequence Trigger:**
   - Day 0: Send Email 1
   - If no reply by Day 2: Send Email 2
   - If no reply by Day 4: Send Email 3
   - If no reply by Day 6: Send Email 4
   - If no reply by Day 7: Send SMS
   - If no reply by Day 10: Send Email 5
   - If no reply by Day 30: Send Email 6
   - If still no reply: Mark as "Dead Lead" (remove from sequence)

3. **Reply Handling:**
   - If reply = "YES" or "Interested": Tag as "Demo Requested", send Calendly link
   - If reply = "Not interested": Tag as "No", ask for feedback
   - If reply = "Later": Tag as "Nurture", add to 90-day re-engagement sequence

4. **Demo Booking:**
   - Calendly sends confirmation email with:
     - Demo link (Zoom)
     - Prep questions (agency size, current EVV solution, no-show rate)
     - ROI calculator link
   - 1 hour before demo: Send SMS reminder

5. **Post-Demo:**
   - If interested: Send pilot agreement + onboarding checklist
   - If on the fence: Send case study + schedule follow-up call
   - If not interested: Ask for feedback, remove from sequence
