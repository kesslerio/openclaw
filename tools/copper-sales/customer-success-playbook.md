# Customer Success Playbook - Copper AI

**Purpose:** Guide for onboarding, supporting, and retaining pilot agencies  
**Goal:** 90%+ retention, 9+ NPS, successful conversions from trial to paid  
**Owner:** Customer Success Manager (future hire) / Arvind (interim)

---

## Philosophy

**Our Job:** Make agencies successful with Copper AI, not just sell them software.

**Success = Agency sees clear value:**

- No-show rate drops by 30%+ in 8 weeks
- Admin time saved is visible (hours back per week)
- Caregivers adopt it (90%+ usage)
- Client complaints decrease (measurable)

**If they succeed, they stay. If they don't, they churn.**

## Phase 1: Pre-Onboarding (Week 0)

### After Pilot Agreement Signed

**Within 24 Hours:**

- [ ] Send welcome email with:
  - Onboarding call calendar link
  - Pre-onboarding checklist (what to gather)
  - Demo environment link (let them explore)
  - Your direct contact info (Arvind's phone/email)

**Before Onboarding Call:**

- [ ] Review their demo notes (what excited them?)
- [ ] Check their EMR (ClearCare or Axxess)
- [ ] Estimate their baseline (current no-show rate, visits/month)
- [ ] Prepare personalized ROI projection

## Phase 2: Onboarding (Week 1)

### Onboarding Call (30-60 min)

**Agenda:**

**1. Goals & Expectations (10 min)**

- "What does success look like for you in 8 weeks?"
- Document their answer (this is their success criteria)
- Set realistic expectations:
  - Week 1-2: Learning curve (adoption building)
  - Week 3-4: Early results (15-20% reduction)
  - Week 5-8: Full impact (30-45% reduction)

**2. Technical Setup (20 min)**

**For ClearCare Agencies:**

- [ ] Connect Zapier account (or we do it for them)
- [ ] Set up email forwarding to Zapier
- [ ] Test webhook (send dummy visit → verify in dashboard)
- [ ] Confirm voice hotline number

**For Axxess Agencies:**

- [ ] Get API credentials (they request from Axxess support)
- [ ] Connect API client (we handle OAuth flow)
- [ ] Test API connection (fetch caregivers)
- [ ] Confirm voice hotline number

**3. Caregiver Import (10 min)**

- Upload caregiver CSV (name, phone, email)
- OR: Auto-sync from Axxess API
- Review caregiver list (ensure accuracy)
- Identify 3-5 "champions" (top performers to test first)

**4. Test Voice EVV (10 min)**

- Have agency admin call the hotline
- Demonstrate: "Hi, this is [Admin Name], clocking in for test patient"
- Show real-time update in dashboard
- Explain caregiver announcement (email + staff meeting)

**5. Launch Plan (10 min)**

- [ ] Week 1: Test with 3-5 caregivers (champions)
- [ ] Week 2: Expand to 50% of caregivers
- [ ] Week 3: Roll out to all caregivers
- [ ] Week 4-8: Monitor, optimize, track results

**Post-Call:**

- [ ] Send onboarding summary email (steps completed, next actions)
- [ ] Share caregiver announcement template (email + poster)
- [ ] Schedule Week 1 check-in (30 min)

## Phase 3: Early Adoption (Week 1-2)

### Week 1 Check-In Call (30 min)

**Agenda:**

**1. Adoption Check (10 min)**

- How many caregivers have used it? (target: 3-5)
- What feedback have you heard? (positive + negative)
- Any technical issues? (voice quality, errors)

**2. Usage Review (10 min)**

- Show them the dashboard (their data)
- Walk through: Scheduled visits, risk scores, confirmation calls
- Highlight: HIGH-risk visits (explain risk factors)

**3. Early Results (5 min)**

- "Any no-shows this week vs last week?"
- Celebrate wins (even if small)
- "Sarah used the voice EVV 3 times - that's great!"

**4. Next Steps (5 min)**

- [ ] Expand to 10-15 more caregivers (50% of team)
- [ ] Share positive feedback in team meeting
- [ ] Address any concerns (voice quality, confusion)
- [ ] Schedule Week 2 check-in

---

### Week 2 Check-In Call (30 min)

**Agenda:**

**1. Adoption Check (10 min)**

- How many caregivers using it now? (target: 50%+)
- Any holdouts? (why? address concerns)
- Caregiver sentiment? (do they like it?)

**2. No-Show Trends (10 min)**

- Review: No-shows this week vs baseline
- Show trend chart (hopefully declining)
- Identify: Which caregivers are high-risk?

**3. Admin Time Savings (5 min)**

- "How much time are you saving on confirmations?"
- Estimate hours saved (compare to manual calls)
- Document for ROI report

**4. Full Rollout Plan (5 min)**

- [ ] Expand to 100% of caregivers (Week 3)
- [ ] Announce success stories in team meeting
- [ ] Set up weekly ROI reports (automated)
- [ ] Schedule Week 4 check-in (track full impact)

**1. Full Adoption Check (10 min)**

- Usage rate: What % of caregivers using it? (target: 90%+)
- Identify laggards (who's not using it? why?)

**4. Next Steps (optional)**

- [ ] Testimonial (video or written)

## Success Metrics (Track Per Agency)

### Leading Indicators (Early Signals)

- **Week 1-2:**
  - Caregiver adoption rate: >50% by Week 2
  - Voice call success rate: >95% (calls go through)
  - Admin engagement: Logging in daily?

### Lagging Indicators (Results)

- **Week 4-8:**
  - No-show rate: 30%+ reduction from baseline
  - Admin time saved: 40+ hours/month
  - Caregiver NPS: 8+ / 10
  - Client complaints: 50%+ reduction

### Retention Signals (Churn Risk)

- 🚩 **Red Flags:**
  - Low adoption (<70% caregivers using it)
  - Increasing no-shows (not declining)
  - Admin not logging in (disengaged)
  - No response to check-in emails

- ✅ **Healthy Signals:**
  - High adoption (90%+ caregivers)
  - Declining no-show trend
  - Proactive questions (engaged)
  - Referrals to other agencies

## Churn Prevention

### When Agency is At Risk

**Identify early (Week 2-4):**

- Low adoption: <70% caregivers using it
- No results: No-show rate unchanged
- Disengaged: Not responding to check-ins

**Intervention Steps:**

**1. Discovery Call (30 min)**

- "What's not working for you?"
- Listen: Understand real issue (technical? adoption? expectations?)
- Document: Their concerns (be specific)

**2. Action Plan (same call)**

- Fix technical issues immediately (if that's the problem)
- Adjust expectations (if they're unrealistic)
- Offer hands-on help (if adoption is the issue)

**3. Weekly Touch Points (until resolved)**

- Don't wait for scheduled check-ins
- Proactive: "Just checking in, how's it going?"
- Show you care: Their success is your priority

**4. Escalate if Needed**

- If still struggling after 2 weeks → Arvind gets involved
- Offer: On-site visit (if local)
- Last resort: Extended trial (extra 30 days to prove value)

## Common Issues & Solutions

### Issue 1: Low Caregiver Adoption

**Symptoms:** <70% of caregivers using voice EVV

**Root Causes:**

- Caregivers don't understand how (need training)
- Forget the hotline number (need reminder)
- Prefer old system (change resistance)

**Solutions:**

- [ ] Laminated wallet cards (hotline number + instructions)
- [ ] Team meeting demo (show it live)
- [ ] Incentive: $5 bonus for first 3 uses (jumpstart adoption)
- [ ] Champions: Have top performers demonstrate for others

---

### Issue 2: No-Show Rate Not Improving

**Symptoms:** No-show rate unchanged after 4 weeks

**Root Causes:**

- Not using predictive features (just basic calls)
- HIGH-risk visits not being prioritized
- Confirmation calls too late (not 2 hours before)

**Solutions:**

- [ ] Review dashboard with admin (show HIGH-risk visits)
- [ ] Enable auto-confirmation (instead of manual)
- [ ] Adjust timing: 2 hours before (not 24 hours)
- [ ] Check: Are backup caregivers being contacted?

---

### Issue 3: Technical Problems

**Symptoms:** Voice calls failing, integrations breaking, errors

**Root Causes:**

- EMR credentials changed (Axxess OAuth expired)
- Caregiver phone numbers wrong (bounced calls)
- Zapier workflow paused (ClearCare integration)

**Solutions:**

- [ ] Check logs (identify error pattern)
- [ ] Test integration (verify EMR connection)
- [ ] Update credentials (re-authorize if needed)
- [ ] Escalate to engineering (if bug)

---

### Issue 4: Expectations Mismatch

**Symptoms:** "It's not working" (but it is, just slowly)

**Root Causes:**

- Expected instant results (Week 1 vs Week 8)
- Baseline was wrong (thought they had 20% but actually 15%)
- Unrealistic goals ("eliminate all no-shows")

**Solutions:**

- [ ] Reset expectations (show realistic timeline)
- [ ] Re-calculate baseline (use their actual data)
- [ ] Celebrate progress (15% → 12% = 20% reduction, that's good!)
- [ ] Show trend chart (improving over time, even if slow)

**When to Upsell:**

- Proactive risk prediction is working (they see HIGH-risk alerts)

**Pitch:**

### Pro → Enterprise ($800 → $2,000+/mo)
