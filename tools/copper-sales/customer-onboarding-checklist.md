# Copper AI Customer Onboarding Checklist

_Complete 30-Day Onboarding Program for Home Health Agencies_

**Goal:** Get customers to "aha moment" (first no-show prevented) within 7 days

---

## 📋 Pre-Kickoff (Before Day 1)

### Account Setup

- [ ] Create agency account in Copper AI system
- [ ] Generate unique phone number for agency
- [ ] Set up ClearCare/Axxess integration (if applicable)
- [ ] Configure timezone (CST, EST, PST, etc.)
- [ ] Set agency working hours (6 AM - 10 PM typical)

### Gather Information

- [ ] Agency name & contact info
- [ ] Primary contact (owner/ops manager)
- [ ] Number of caregivers
- [ ] Number of monthly visits
- [ ] Current no-show rate (baseline)
- [ ] Current EVV compliance rate (baseline)
- [ ] Pain points (#1 priority to solve)

### Prepare Materials

- [ ] Welcome email with credentials
- [ ] Quick-start guide (1-page PDF)
- [ ] Caregiver training video (2-3 min)
- [ ] Schedule Day 1 kickoff call (30 min)

**Deliverable:** Welcome packet sent 24 hours before kickoff

---

## Day 1: Kickoff Call (30 minutes)

### Attendees

- [ ] Arvind (or Nike if voice-enabled)
- [ ] Agency owner or operations manager
- [ ] Optional: Lead caregiver (for buy-in)

### Agenda

**Minutes 1-5: Set Expectations**

```
"By the end of this week, you'll prevent your first no-show.
By end of month, you'll see 30-50% reduction in no-shows.
Our job is to make you wildly successful."
```

**Minutes 5-10: Understand Their Pain**

- What's your biggest challenge right now?
- No-shows? EVV compliance? Caregiver turnover?
- How do you currently handle schedule changes?
- _(Take notes — customize onboarding based on their #1 pain)_

**Minutes 10-20: Technical Setup**

- [ ] Add caregivers to Copper AI (names, phone numbers)
- [ ] Connect to ClearCare/Axxess (if applicable)
- [ ] Test call: "Let's call your phone right now and simulate a clock-in."
- [ ] Walk through caregiver dashboard (if they have one)

**Minutes 20-25: Set Success Metrics**

```
"Your current no-show rate is X%. Let's track this weekly.
Goal: Reduce to Y% by end of month."
```

- [ ] Define success metrics (no-show rate, EVV compliance)
- [ ] Set weekly check-in schedule

**Minutes 25-30: Next Steps & Timeline**

- [ ] Day 2-3: Caregivers start using Copper AI
- [ ] Day 7: First check-in (15 min call)
- [ ] Day 14: Mid-month review (analyze metrics)
- [ ] Day 30: Success review (celebrate wins!)

### Post-Call Deliverables

- [ ] Send follow-up email within 1 hour
  - Meeting recap
  - Login credentials (if not sent earlier)
  - Quick-start guide (1-page PDF)
  - Calendar invite for Day 7 check-in
- [ ] Add notes to CRM (pain points, goals, contact preferences)

## Day 2-3: Caregiver Training (Automated)

**Don't rely on agencies to train caregivers — Copper AI does it.**

### Automated Training Process

- [ ] Copper AI calls each caregiver (within 24 hours of onboarding)
- [ ] Walkthrough script:
  ```
  "Hi Sarah, this is Copper AI. I'm the new voice assistant for
  [Agency Name]. From now on, you can call me to clock in/out,
  check your schedule, or confirm visits. Let's do a quick practice
  run. Ready?"
  ```
- [ ] Practice scenarios:
  - "Say: Clock me in for Mrs. Johnson's visit."
  - "Say: What's my schedule today?"
  - "Say: I'm running 10 minutes late."
- [ ] Confirm understanding:
  ```
  "Great job! You're all set. Call me anytime at [number].
  See you soon!"
  ```

### Success Metrics

- [ ] 90% of caregivers complete training call within 48 hours
- [ ] Track which caregivers haven't been trained (follow-up manually)

### Manual Follow-Up (If Needed)

- [ ] Text caregivers who haven't called: "Hi Sarah, this is Copper AI. Call [number] to complete your quick training. Takes 2 minutes!"
- [ ] Email agency owner with adoption rate: "18 of 20 caregivers trained (90%). Great start!"

## Day 7: First Check-In (15 minutes)

### Pre-Call Prep

- [ ] Pull metrics from Day 1-7:
  - No-shows prevented (count)
  - $ saved (no-shows × avg visit value)
  - Caregiver adoption rate
  - Call volume (total calls to Copper AI)
- [ ] Identify any issues (caregivers not using, technical glitches)

### Call Agenda

**Minutes 1-5: Celebrate Wins**

```
"You prevented 3 no-shows this week! That's $450 saved. Amazing start."
```

- [ ] Lead with wins (positive reinforcement)
- [ ] Show specific examples: "Sarah called Tuesday to confirm her visit, preventing a no-show."

**Minutes 5-10: Address Issues**

```
"Have any caregivers had trouble using Copper AI?"
```

Common issues & solutions:

- [ ] Caregiver forgot phone number → Send SMS reminder
- [ ] Caregiver doesn't speak English well → Enable Spanish mode
- [ ] Technical glitch (calls not connecting) → Fix immediately, apologize
- [ ] Caregiver prefers mobile app → Explain why voice is better (hands-free, easier)

**Minutes 10-15: Set Next Week's Goal**

```
"Let's aim for 5 no-shows prevented next week. I'll check in again on Day 14."
```

- [ ] Set clear goal (specific number)
- [ ] Confirm next check-in time

### Post-Call Deliverables

- [ ] Send email recap with updated metrics
- [ ] If issues identified: Follow up within 24 hours with fix
- [ ] Update CRM notes

---

## Day 14: Mid-Month Review (15 minutes)

### Pre-Call Prep

- [ ] Pull metrics from Day 1-14:
  - Total no-shows prevented
  - Total $ saved
  - EVV compliance rate
  - Caregiver adoption rate (% using Copper AI)
  - Comparison to baseline (before Copper AI)

### Call Agenda

**Minutes 1-5: Review Metrics**

```
"You're crushing it! 8 no-shows prevented = $1,200 saved in 2 weeks."
```

- [ ] Show before/after comparison
- [ ] Highlight improvement trends

**If Metrics Are Good:**

```
"Keep it up! You're on track to save $2,500+ this month."
```

- [ ] Reinforce success
- [ ] Ask if they'd recommend Copper AI to other agencies (referral seed)

**If Metrics Are Bad:**

```
"I notice adoption is lower than expected. Let's troubleshoot.
Which caregivers aren't using it? I can call them directly and help."
```

- [ ] Identify root cause (technical issue? Training issue? Resistance?)
- [ ] Offer solutions (re-training, Spanish mode, incentives for adoption)

**Minutes 5-10: Adjust Strategy (If Needed)**

- [ ] If low adoption: Schedule caregiver group call or send training video
- [ ] If high adoption but low no-show prevention: Check if confirmation calls are happening 2 hours before visits
- [ ] If technical issues: Escalate to engineering (Arvind)

**Minutes 10-15: Set Goals for Next 2 Weeks**

- [ ] Specific goal: "10 no-shows prevented by Day 30"
- [ ] Confirm Day 30 success review time

### Post-Call Deliverables

- [ ] Midpoint report (1-page PDF with metrics)
- [ ] If adjustments needed: Follow-up email within 24 hours
- [ ] Update CRM notes

## Day 30: Success Review & Lock-In (30 minutes)

**This is the MOST IMPORTANT call. Goal: Prove ROI and secure renewal commitment.**

### Pre-Call Prep

- [ ] Pull full month metrics:
  - No-shows prevented (count + $$ saved)
  - EVV compliance rate (before/after)
  - Admin time saved (hours)
  - Caregiver satisfaction score (survey results)
  - ROI ratio (value delivered ÷ Copper AI cost)
- [ ] Create Month 1 Success Report (PDF, 2-3 pages):
  - Executive summary (1 paragraph)
  - Metrics with graphs (before/after comparison)
  - Testimonial quotes (if available)
  - Next steps (Q2 goals)
- [ ] Prepare testimonial request (video or written)

### Call Agenda

**Minutes 1-10: Present ROI**

```
"You prevented 12 no-shows this month. At $150/visit, that's $1,800 saved.
Copper AI cost $500. Net savings: $1,300. ROI: 3.6:1.
And this is just month 1 — it gets better from here."
```

- [ ] Walk through success report
- [ ] Show before/after graphs (visual impact)
- [ ] Emphasize: "This is with just 1 month of data. Imagine a full year!"

**Minutes 10-15: Gather Testimonial**

```
"Can I ask you to record a short video testimonial? Just 60 seconds:
- What problem did Copper AI solve for you?
- What results did you see?
- Would you recommend it to other agencies?"
```

- [ ] Record testimonial (screen recording or phone)
- [ ] Get permission to use on website/marketing

**Minutes 15-25: Upsell / Lock-In**

```
"Love that you're seeing results. Two options to lock in this value:
1. Annual Plan: Pay $5,000 upfront (save $1,000/year, 2 months free)
2. Month-to-month: Continue at $500/month

Most agencies go annual because it's guaranteed savings. What makes sense for you?"
```

- [ ] Present annual plan benefits (20% discount, price lock, priority support)
- [ ] If hesitant: Offer quarterly plan ($1,400 for 3 months, save $100)
- [ ] If committed: Send contract immediately

**Minutes 25-30: Set Long-Term Goals**

```
"What's your goal for Quarter 2? No-show rate below 3%?
Let's track it together."
```

- [ ] Define Q2 goals (3-month targets)
- [ ] Schedule next QBR (Quarterly Business Review) for Month 3

### Post-Call Deliverables

- [ ] Month 1 Success Report (PDF, send within 24 hours)
- [ ] Annual contract (if they signed) or renewal reminder (if month-to-month)
- [ ] Q2 goal-setting email
- [ ] Add testimonial to website/marketing materials
- [ ] Update CRM: Renewal status, next check-in date

## Red Flags (Early Warning Signs)

If you see these, **take immediate action**:

| Red Flag                           | What It Means           | Action                                         |
| ---------------------------------- | ----------------------- | ---------------------------------------------- |
| **Low caregiver adoption (<70%)**  | Not using Copper AI     | Manual training call, Spanish mode, incentives |
| **Missed Day 7 check-in**          | Disengaged              | Reschedule immediately, email + call           |
| **No no-shows prevented by Day 7** | Not working as expected | Technical audit, adjust settings               |
| **Agency owner not responding**    | 80% churn risk          | Executive escalation (Arvind calls personally) |
