╔════════════════════════════════════════════════════════════════════════╗
║                        TROUBLESHOOTING                                 ║
╚════════════════════════════════════════════════════════════════════════╝

Script won't run?
  - Make sure you're in ~/clawd/scripts directory
  - Check if script is executable: chmod +x script-name.sh
  - For Node scripts: Use 'node script.js' not just './script.js'
  - For Python scripts: Use 'python3 script.py'

Missing Playwright?
  - Run: npx playwright install
  - Fixes: get-youtube-transcript.js, yt-transcript-playwright.js

Get help for any script?
  - node script.js --help
  - ./script.sh --help
  - python3 script.py --help

Check if script works:
  - Look for "✅" in output (success)
  - Look for "❌" in output (error)
  - Exit code 0 = success, non-zero = error


╔════════════════════════════════════════════════════════════════════════╗
║                       QUICK TIPS                                       ║
╚════════════════════════════════════════════════════════════════════════╝

1. Use 'all' to see all templates:
   node email-campaign-generator.js all
   node linkedin-post-generator.js all

2. Pipe output to file for editing:
   node linkedin-post-generator.js no-shows > post.txt

3. Chain commands:
   node sales-call-prep.js --pain "no-shows" && \
   node roi-calculator-cli.js --calls 1000

4. Create aliases in ~/.zshrc:
   alias prep="node ~/clawd/scripts/sales-call-prep.js"
   alias roi="node ~/clawd/scripts/roi-calculator-cli.js"
   alias metrics="node ~/clawd/scripts/copper-metrics-tracker.js"

5. Schedule weekly reports with cron/launchd
